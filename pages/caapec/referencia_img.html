Redirecionamento com Imagem

Múltiplas formas de fazer uma imagem redirecionar para outra página

Método 1: Link <a>

RECOMENDADO

A forma mais semântica e acessível. Envolva a imagem com uma tag <a> para criar um link clicável.

<!-- Exemplo básico -->
<a href="pagina-destino.html">
  <img src="imagem.jpg" alt="Descrição da imagem">
</a>

<!-- Com atributos extras -->
<a href="https://exemplo.com" target="_blank">
  <img src="imagem.jpg" alt="Descrição">
</a>

Vantagens: Semântico, acessível, funciona sem JavaScript, indexável por buscadores.

Método 2: JavaScript

DINÂMICO

Adicione um evento de clique via JavaScript para redirecionamento dinâmico ou condicional.

<!-- HTML -->
<img id="minhaImagem" src="imagem.jpg" alt="Descrição">

<!-- JavaScript -->
<script>
  document.getElementById('minhaImagem')
    .addEventListener('click', function() {
      window.location.href = 'pagina-destino.html';
    });
</script>

Vantagens: Controle total, pode adicionar lógica condicional, animações antes do redirecionamento.

Método 3: CSS como Link

ESTILIZADO

Use CSS para transformar um elemento em um link clicável com imagem de fundo.

<!-- HTML -->
<a href="destino.html" class="image-button">
  Texto do Link
</a>

/* CSS */
.image-button {
  display: inline-block;
  width: 300px;
  height: 200px;
  background-image: url('imagem.jpg');
  background-size: cover;
  text-indent: -9999px; /* Esconde texto */
  border-radius: 10px;
}

Vantagens: Maior controle sobre o posicionamento da imagem, fácil de fazer responsivo.
