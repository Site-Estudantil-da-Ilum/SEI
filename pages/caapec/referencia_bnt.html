Botão com Imagem em HTML/CSS

Exemplos das melhores práticas para criar botões com imagens de forma semântica, acessível e responsiva.

1. Botão com Imagem + Texto (Recomendado)

MELHOR PRÁTICA

Usando a tag <button> semanticamente correta com imagem interna e texto visível.

<button class="btn-with-img">
    <img src="caminho/para/imagem.png" alt="Ícone descritivo">
    Texto do Botão
</button>

2. Botão Apenas com Imagem

ACESSÍVEL

Para botões de ícone, mantenha a acessibilidade com atributos aria-label ou texto escondido.

<button class="img-only-btn" aria-label="Ação do botão">
    <img src="icone.png" alt="Ícone descritivo">
</button>

3. Botão com Imagem como Background

CSS BACKGROUND

Usando CSS para definir a imagem como fundo do botão.

<button class="bg-img-btn">Comprar Agora</button>

.bg-img-btn {
    background-image: url('caminho/para/imagem.png');
    background-size: 30px;
    background-repeat: no-repeat;
    background-position: 25px center;
    padding-left: 70px;
}

4. Botão com Efeitos Avançados

ANIMAÇÕES CSS

Exemplo com efeitos de hover, animações e transições.

<button class="advanced-btn">
    <img src="icone.png" alt="Ícone">
    Adicionar ao Carrinho
</button>

Principais Vantagens desta Abordagem:

  • Semântica correta: Usa a tag <button> para ações
  • Acessibilidade: Compatível com leitores de tela e navegação por teclado
  • Responsividade: Se adapta a diferentes tamanhos de tela
  • Performance: Imagens otimizadas com atributos alt descritivos
  • Manutenibilidade: Fácil de estilizar e modificar
